## 5. LLM 생성

| 항목 | 내용 |
|---|---|
| 대상 | 제외 사유 없는 132,122건 |
| 모델 | GPT-4.1 mini |
| 입력 | 제목, 본문(앞 2,500자), 대회·제도명, 출처 정보 |
| 검증 | 근거 구절이 원문에 그대로 없으면 `unverified`로 제외 |

| 필드명 | 이름 | 생성 내용 | 예 ("모든 서울시 시설공단 통합 하여 예산절약") |
|---|---|---|---|
| `label` | 판정 | 글의 성격. idea(아이디어) / idea_thin(빈약) / complaint(불만·항의) / off_topic(광고·무관) / abusive(욕설·비방) | idea |
| `item_type` | 유형 | product(발명·제품·디자인·서비스) / research(과학 탐구) / policy(정책·시민 제안) | policy |
| `goal` | 목표 | 해결하려는 문제 한 문장. 탐구는 알아내려는 것 | 서울시 및 자치구 시설공단의 비효율과 부패 문제 개선 |
| `solution` | 해결책 | 만든 것 또는 방법 한 문장. 탐구는 실험 방법과 결과 | 모든 서울시 시설공단을 통합하여 인건비 절감 및 투명한 관리 |
| `features` | 핵심 기능 | 핵심 기능 0~3개. 탐구는 만든 장치·앱이 있을 때만 | 시설공단 통합, 인건비 절감, 투명한 관리 |
| `domain` | 분야 | 1~2개. 행정·복지·교통·환경·경제·교육·안전·문화·보건·과학기술·생활·기타 | 행정, 경제 |
| `evidence` | 근거 | 해결책을 뽑은 원문 구절 | 모든지자체 공공기관 사업소를 통합하여 관리함 |
| `verified` | 근거 확인 | 근거 구절이 원문에 그대로 있으면 true | true |

- `label`은 132,122건 모두 생성
- `item_type`~`verified`는 `label`이 idea인 120,187건에만 생성

| 판정 | 132,122 |
| 아이디어 | 120,187 |
