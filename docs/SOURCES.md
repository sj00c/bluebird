### 중복·개인정보·공개 경계

- 출처 내 동일 수집 콘텐츠는 중복 제거. 실제 원천 ID가 없는 경우 순번·연락처 등 제외 컬럼을 ID 계산에 쓰지 않음.
- 소문자·문자/숫자 기준으로 정규화한 **제목+연도**가 출처 간 일치하는 경우: 472그룹, 980레코드. 이 중 기존·신규를 함께 포함하는 그룹은 302개. 유사 제목만으로 동일 아이디어라고 판정하거나 출처를 삭제하지 않음.
- 신규 과학관 아카이브 중 기존 과학관 CSV와 제목+연도가 같은 기록은 296건. 신규 고유 아이디어로 단정하지 않음.
- 제공된 성명과 정규화 결과 대조: 남은 성명 일치 0건. 인물·학교·연락처 전용 컬럼은 적재 제외. 자유서술에서 자기소개 이름 위험이 확인된 출처는 본문 매핑 제외.
- 연락처 패턴 1건은 행복농촌 원문의 식당 안내 문맥에서 검출. 이 자동 점검이 모든 개인정보의 부재를 보증하지 않으며 원문 공개 검토는 별도.
- 시험용 진단·점수·매칭·승인·이의·해석 흔적 삭제. 수집이 이를 재생성하지 않음. 기존 원문 발췌·실제 특허 연결·카탈로그 관측은 보존.
- 기존 시험용 공개 승인도 철회해 **66개 소스 모두 보류**, 공개 스냅샷은 0건. 수집 원본은 인증된 콘솔에서 조회하며 공개 건수를 늘리려고 권한을 우회하지 않음.
- 외부 서비스 API 키는 현재 미설정. 이번 수집은 익명 접근이 확인된 공식 파일·목록만 사용.

- `trace auto`: NAVER 뉴스와 KIPRIS Plus 특허·실용신안 키워드 검색. 각 첫 페이지 최대 10건의 제한 검색이며 상표·법인 조회를 포함하지 않는다. 발견한 문서는 후보이고 사업화 여부는 사람이 해석한다.

- 키 누락이나 검색 오류는 미실시 상태다. 확인된 검색 결과 없음(`none`)과 구분한다.
- `diagnose auto`는 실제 본문 발췌, `score auto`는 등록된 변화 근거에 한정해 제안한다. 근거 URL을 모델이 새로 만들어 붙이지 않는다. 승인·공개는 담당자와 공개 배치를 거친다.

## 7. 참고할 서비스·오픈소스 (기능 벤치마크)

**아이디어 관리 상용 서비스**: Ideanote(임베딩 군집·중복 탐지·AI 병합), Qmarkets(군집 기준을 프롬프트로 지정), HYPE(아이디어와 외부 트렌드를 함께 군집), Planview IdeaPlace(옛 Spigit, 중복 자동 병합), Brightidea, IdeaScale.
→ 파랑새에 가져올 기능: 유사 아이디어 묶음, 중복 표시, 주제 군집 지도.

**시민 참여 오픈소스**: Decidim(바르셀로나, AGPL), CONSUL Democracy(마드리드, AGPL, 제안 CSV 내보내기·LLM 기능). 의견 수렴 보드: Fider, LogChimp.
→ 이의 제기·의견 기능 설계 참고. 코드를 가져다 쓸 대상은 아님.

**AI 아이디어 생성·검증 오픈소스**: SakanaAI AI-Scientist v2(아이디어 생성 + 선행 문헌 신규성 확인), Stanford AI-Researcher(생성 → 유사 문헌 비교 → 중복 제거), ResearchAgent, Chain-of-Ideas, SciMON.
→ "기가 막힌 아이디어 제안" 단계의 구조 참고: 후보 생성 → 기존 풀·특허·뉴스와 비교해 신규성 확인 → 근거 첨부.

## 8. 우선순위

1. `./demo.sh collect`로 검증된 공식 출처 갱신. 공모전과 시민제안은 별도 집계.
2. 기존·신규 출처의 실제 공개·외부전송 권한 검토. 원본 공개 허용과 개별 분석 승인은 별개.
3. 권익위 서비스키 발급 후 실제 공개제안 응답 스키마·페이지 범위 확인 및 적재 연결.
4. 모두의 아이디어·아이디어로 등은 데이터 제공 협의. 후보 규모를 현재 DB 건수에 더하지 않음.
5. [KIPRIS 공식 상품](https://plus.kipris.or.kr/portal/data/util/DBII_000000000000228/view.do?menuNo=210007&subTab=SC002)은 1964–2015 범위·2022년 말 기준 약 38,000건으로 안내. REST/BULK는 로그인·신청이 필요하며, 현재 보유 1979–2014 이후 전체를 익명으로 받는 경로는 확인되지 않음.
