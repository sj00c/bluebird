# 벡터 DB + 사업화 판정 계획 (검토용)

목표: 숨겨진 공모전 아이디어 찾기 = **아직 사업화되지 않았고** + 지금 실현 조건이 갖춰진 아이디어

## 1. 벡터로 만들 데이터

### 아이디어 (114,781건, 사용 대상 전부)

한 건 = 아래 형식의 글 1개 → 벡터 1개

```
[유형] 제목
목표: …
해결책: …
핵심 기능: …, …
```

| 넣음 | 이유 |
|---|---|
| 유형(발명·제품 / 탐구 / 정책·시민 제안) | 같은 주제라도 제품과 정책 제안은 다른 것 |
| 제목, 목표, 해결책, 핵심 기능 | 아이디어의 핵심. 길이가 고르고(평균 150자 안팎) 잡음 없음 |

| 안 넣음 | 이유 |
|---|---|
| 본문 | 길이 차이 큼(80자~수천 자), 인사말·화면 글자 섞임 → 검색이 본문 길이에 끌려감 |
| 분야, 대회명, 연도, 종류 | 벡터 대신 검색 조건(필터)으로 씀 |

### 사업화 비교 대상 (2단계)

| 대상 | 출처 | 벡터로 만들 글 |
|---|---|---|
| 이미 제품이 된 것 | 굿디자인 선정 제품 2,084건(이미 DB에 있음) | 아이디어와 같은 형식 |
| 특허·실용신안 | KIPRIS 특허 검색 | 발명 명칭 + 요약 |
| 뉴스 | 네이버 뉴스 검색 | 제목 + 요약 |
| 창업·후속 지원 | 창업경진 본선 68건(DB), K-Startup 선정 공고 | 기업명 + 아이템 설명 |

## 2. 돌리는 방법

| 항목 | 정한 값 |
|---|---|
| 모델 | OpenAI `text-embedding-3-small`, 1536차원 |
| 비용·시간 | 114,781건 약 0.5달러, 30분 안쪽 [추정] |
| 저장 | master에 `embedding` 칸 1개(서버 `pgvector`) |
| 검색 색인 | HNSW, 코사인 거리 |
| 갱신 | 목표·해결책이 바뀌어 AI 칸이 비워진 행 = 벡터도 비움 → 다시 만듦 |
| 바이브코더용 | 아이디어 + 벡터 파일(Parquet) 내보내기, 질문 → 벡터 → 상위 N개 예제 |

## 3. 사업화 판정

"같은 출품작"(중복 정리용, 같은 작품이 여러 출처에 실린 것)과는 다른 것. **같은 아이디어가 다음 단계로 갔는지**를 봄

### 단계

| 단계 | 뜻 | 확인 근거 |
|---|---|---|
| 0 아이디어 | 제안·출품만 | – |
| 1 수상·선정 | 공모전 수상, 참여예산 선정 | 원본 수상 등급(이미 있음) |
| 2 권리화 | 특허·실용신안 출원 | KIPRIS |
| 3 창업·지원 | 창업경진 본선, 후속 지원사업 선정, 법인 설립 | 창업경진·K-Startup 공고 |
| 4 제품·서비스 출시 | 판매·운영 중 | 굿디자인 선정 제품, 뉴스 |

### 판정 방법

1. 벡터 검색: 아이디어마다 비교 대상에서 가까운 후보 상위 5개
2. LLM 확인: "이 후보가 같은 아이디어가 실현된 것인가" → 예/아니오 + 이유 한 줄
3. 예 = 그 단계 + 근거 링크 저장. 가장 높은 단계를 대표로

### 저장

| master 칸 | 내용 |
|---|---|
| `stage` | 위 단계 0~4 |
| `stage_evidence` | 근거 링크와 한 줄 설명 |

### 규모 조절

- DB 안 비교(굿디자인·창업경진 본선): 114,781건 전부, 비용 작음
- 외부 검색(KIPRIS·뉴스): 일일 호출 한도 있음 → 오래된 아이디어·수상작 등 후보 수천 건 먼저

## 4. 품질 확인

| 확인 | 정답 | 숫자 |
|---|---|---|
| 같은 작품 찾기 | 중복으로 묶인 같은 출품작 1,150쌍 | 한쪽 검색 → 다른 쪽이 상위 5개 안에 드는 비율 |
| 사업화 판정 | LLM이 예라고 한 표본 50건 | 직접 확인한 정답 비율 |
| 검색 체감 | 질문 20개 | 상위 10개 중 관련 있는 수 |

## 5. 순서

1. 서버 PostgreSQL 이미지 → `pgvector/pgvector:pg16`(서버 관리자)
2. 아이디어 벡터 만들기 → 같은 작품 찾기 확인
3. DB 안 사업화 비교(굿디자인·창업경진 본선) → 표본 확인
4. 외부 검색(KIPRIS·뉴스) 후보 범위 정하고 실행
5. 바이브코더용 파일 내보내기

## 정할 것

- 서버 이미지 교체 시점
- 사업화 단계 정의(3장 표) 이대로 갈지
- 외부 검색 키: KIPRIS Plus·네이버 API 키(`.env`에 없음)
